# Introduction

**Flnc 2** (_<ins>F</ins>inding <ins>lnc</ins>RNA_) is a deep learning pipeline for discovering long noncoding RNAs (lncRNAs) in human and mouse. It goes from raw RNA-seq reads or an existing transcript annotation to a set of high-confidence lncRNA candidates.

* Accepts either RNA-seq reads or a BED file of transcripts as input
* End-to-end processing from reads: alignment, transcript assembly, removal of protein-coding transcripts, feature generation, and lncRNA classification
* Deep learning classifier trained to tell lncRNAs apart from other transcripts in human and mouse
* Supports both the human and mouse genomes
